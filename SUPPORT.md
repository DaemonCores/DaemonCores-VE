Support is provided through GitHub issues on a best-effort basis.

## Before opening an issue

Read the [README](README.md) and [architecture documentation](docs/architecture.md), search existing issues, and include:

- image digest or commit;
- installation method;
- relevant hardware or VM configuration;
- Proxmox and project package versions;
- failed units, journal excerpts, and reproduction steps;
- whether the problem also occurs on standard Proxmox VE.

## Project scope

The project can investigate its bootc image, package repacks, installer, pmxcfs integration, default policy, custom host tools, and shared pipeline behaviour.

Problems reproducible on an unmodified Proxmox VE host should be reported upstream. Enterprise subscription and repository support belongs to Proxmox. Hardware-control and storage features require platform-specific qualification and cannot be guaranteed from QEMU test results.

The project does not provide paid support, response-time guarantees, or a general production certification. Report security issues privately according to [SECURITY.md](SECURITY.md).
